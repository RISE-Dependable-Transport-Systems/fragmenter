This section covers the foundational data structures and mathematical utilities used throughout WayWise for representing spatial data, performing geodetic transformations, and executing geometric calculations required for navigation and control.

The `PosPoint`

class is the primary data structure for representing a vehicle's state or a waypoint in a route. It extends `QObject`

and encapsulates position, orientation, dynamics, and metadata.

`llh_t`

`xyz_t`

`rpy_t`
